# SLD 图纸解析 — 功能设计说明

> 本文档依据《SLD校验算法说明文档》提炼，**重点描述 SLD 图纸（DXF）解析**的功能边界、数据模型与处理流程；规范性校验、变更校验、柱网匹配及接口返回格式在文末作概要追溯，便于与算法实现对照。

## 2. 解析目标

从 SLD 用 **DXF** 中，在**指定图层**上扫描 **CAD 属性块（INSERT + ATTRIB）**，筛选出带 **`TOOL_ID`** 的块引用，抽取**业务属性**与**几何/显示固有属性**，形成结构化设备记录列表，供后续校验、柱网匹配与前端展示使用。

---

## 3. 输入与前置条件

### 3.1 文件与命名

- **格式**：DXF。
- **文件名约定**（与校验算法一致）：`{Company}^SLD^{Building}^{Level}`（无扩展名部分与业务入参一致时可做文件名校验；解析器本身以文件路径可读为前提）。

### 3.2 运行参数（与 ELD 思路对齐）

- **图层白名单**：仅解析配置中给定的图层上的属性块；未配置或空则策略需在实现中明确（建议：无白名单则解析全部 modelspace INSERT，或强制要求白名单以避免误扫）。
- **Equipment group 列表**（可选）：解析阶段可用于 OWNER → `group_id` 映射；**是否允许 OWNER** 属于允许列表属于**规范性校验**，不在纯解析步骤中失败阻断，除非产品要求解析即过滤。

### 3.3 历史数据（非解析步骤）

- **变更校验**依赖上一版设备数据；图纸解析**不依赖**历史数据，仅产出当前图面快照。

---

## 4. 解析范围与对象定义

### 4.1 图元范围

- 作用空间：**Model Space（模型空间）**。
- 实体类型：仅处理 **`INSERT`（块引用）**。
- 块定义：块名需在文档 `BLOCKS` 中存在；无定义引用可跳过或记诊断（实现可选）。

### 4.2 过滤条件

1. **图层**：`INSERT` 所在图层 ∈ 调用方传入的「特定图层」集合（若启用过滤）。
2. **属性标识**：块引用上必须存在 **非空** 的 **`TOOL_ID`** 属性（tag 不区分大小写时建议统一归一化后比较）。  
   - 与说明文档一致：**解析名称带有 `TOOL_ID` 的属性块**。
3. 无 `TOOL_ID` 或值为空的 `INSERT`：**不进入**设备列表（可打调试日志）。

### 4.3 属性读取规则

- 自每个 `INSERT` 的 **`ATTRIB`** 子实体读取 `tag` → `text`。
- **Tag 归一化**：建议 `strip` + **大写** 后与字段字典匹配，避免图纸写法不一致。
- **`TOOL_ID` 文本规范化**：若行业约定以 `^` 前缀存储，与 ELD 一致时可 **去掉首字符 `^`** 再作为对外 `tool_id`。

### 4.4 业务属性字段（图纸 → 内存）

说明文档中标注为必填的字段在**校验阶段**报错；解析阶段应**尽量原样抽取**（空则空字符串 / null，由 schema 统一）。

| 逻辑名 | 图纸属性 Tag（约定） | 说明 |
|--------|----------------------|------|
| 主设备 | `ID_EQU` | 与 ELD 的 TOOL ID 规范性规则可对齐 |
| 子设备 | `ID_EquSubShort` | 与 `ID_EQU` 组合作为业务主键参与唯一性、变更对比 |
| 设备组 | `OWNER` | 对应 System Matrix 中 Equipment group |
| 厂商 | `VENDOR` | |
| 型号 | `MODEL` | |
| 柱位 | `BAY_LOCATION` | |
| 记录 | `RECORDS` | |
| 工具/展示用 ID | `TOOL_ID` | **过滤门槛**；同时映射为输出中的 `tool_id`（规范化后） |

> **实现提示**：若现场 DWG 导出存在 tag 别名（如子设备字段拼写变体），可在解析层做别名表兼容，并写入设计附录。

### 4.5 固有属性字段（几何与 CAD）

| 输出字段 | 来源 | 说明 |
|----------|------|------|
| `block_name` | `INSERT.dxf.name` | 块名称 |
| `layer` | `INSERT.dxf.layer` | 图层名 |
| `angle` | `INSERT` 旋转角 | 属性块旋转角度 |
| `true_color` | `INSERT` 颜色相关属性 | 真彩色/索引色按 DXF 与库能力取值 |
| `insert_point_x` / `y` / `z` | `INSERT.dxf.insert` | 插入点 |
| `center_point_x` / `y` / `z` | 包围盒或回退插入点 | 说明文档要求中心点 XYZ；建议 **优先** 对 `INSERT` 做几何包围盒（含旋转缩放）取中心，失败则回退插入点 |
| `block_id` | `INSERT.dxf.handle` | 图元句柄，唯一标识该次插入 |

## 5. 处理流程（功能流水线）

```text
读取 DXF
  → 遍历 modelspace
  → 仅 INSERT
  → [可选] 图层过滤
  → 读取 ATTRIB 字典
  → 若无 TOOL_ID 或非空校验失败则跳过
  → 规范化 TOOL_ID → tool_id
  → 计算 center_point_*（含 Z）
  → 组装「单条设备记录」
  → 追加到列表
输出：设备记录列表（+ 可选：原始 tag 列表用于排错）
```

### 5.1 设备记录唯一性键（解析输出侧）

- **图面实例键**：建议 `(block_id)` 或 `(layer, block_id)`，保证同一 DXF 内不重复。
- **业务键**（供下游校验）：`ID_EQU` + `ID_EquSubShort`（字符串连接规则需在实现中固定，例如 `f"{id_equ}|{sub}"`）。

## 6. 输出数据结构（解析层）

解析模块建议输出与说明文档 **§7 `eqp_data` 条目** 对齐的结构（类型以接口契约为准；文档示例多为字符串）。

**单条设备（逻辑字段）**：

- **业务**：`tool_id`, `owner`, `vendor`, `model`, `bay_location`, `records`，以及 **`id_equ`、`id_equ_sub_short`**（若接口沿用 `eqp_data` 仅列 tool_id，则需扩展或放在 `detail` 中，避免丢失 SLD 主键）。
- **柱网（解析后可能为空）**：`grid_x`, `grid_y` — 由 **柱网匹配步骤** 写入，纯解析可为空。
- **固有**：`block_name`, `layer`, `angle`, `true_color`, `insert_point_*`, `center_point_*`, `block_id`。

**与说明文档 JSON 的对应关系**：

- 文档示例字段名 `insert_point_Z` 与 `center_point_z` 混用大小写，**实现建议统一 snake_case 小写** `insert_point_z`、`center_point_z`。
- `grid_x` / `grid_y` 来自柱网定义表 + 最近邻匹配，见 §8。

## 7. 非解析职责边界（概要追溯）

以下步骤在《SLD校验算法说明文档》中与解析并列，**不属于「图纸解析」核心逻辑**，但依赖解析结果：

### 7.1 数据规范性校验（error / warning）

- `ID_EQU` 规范性：与 ELD 的 TOOL ID 校验及错误描述一致；示例 detail 含 CAD 编码、`TOOL_ID`、坐标等。
- `ID_EQU` + `ID_EquSubShort` **全局唯一**（重复则 error）。
- **关键属性缺失** / **必填项未填写**：区分「属性不存在」与「存在但为空」时，文档分别给出 warning 类描述（实现以产品最终定义为准）。
- **设备编组**：`OWNER` 不在允许的 Equipment group 范围内 → warning。

### 7.2 数据变更校验（warning）

对比上一版数据：属性修改、位置变更（同 `TOOL_ID` 或同 `ID_EQU+ID_EquSubShort` 以文档为准）、新增、删除；前端对新增/删除支持「忽略」操作（文档：新增默认不忽略、删除默认忽略）。

### 7.3 设备柱网匹配

- 输入：**柱网定义表**（Company, Building, Field, XY, Value_From, Value_To）。
- 逻辑：以设备 **中心点** 为参考，匹配**最近**柱网坐标，得到 `grid_x`、`grid_y`（与 ELD 柱网思路一致，见项目 `GridPillarFinder`）。

### 7.4 检验返回 JSON（顶层）

```json
{
  "error": [],
  "warning": [],
  "eqp_data": []
}
```

`error` / `warning` 由校验流水线填充；`eqp_data` 为带柱网等 enrichment 后的设备列表。
